#  BMW Creative Clone

A modern, pixel-perfect recreation of the BMW landing page built to practice advanced frontend development techniques, smooth animations, and responsive web design. This project focuses on creating an immersive user experience using modern HTML, CSS, JavaScript, and animation libraries.

> **Disclaimer:** This project is created solely for educational and portfolio purposes. It is not affiliated with or endorsed by BMW. All trademarks, logos, and brand assets belong to their respective owners.

---

## ✨ Features

- Modern BMW-inspired UI
- Smooth Scroll Experience
- Creative Page Transitions
- Interactive Navigation
- Scroll-based Animations
- High Performance & Clean UI
- Mobile Friendly
- Reusable Code Structure

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- GSAP (GreenSock Animation Platform)
- Lenis Smooth Scroll

---

### Open

Simply open `index.html` in your browser or use VS Code Live Server.
